# English Wordbook - Chinese documentation

English documentation: [README.md](./README.md)

Obsidian 学习插件：内置 1.3 万词条离线词典与完整四六级词书，提供造句批改、长难句英译中、收藏批注高光等练习流。AI 能力通过「自带 Key 直连」OpenAI 兼容接口实现，数据全部保存在你的仓库本地。

## 功能亮点

- **离线词典**：内置约 1.3 万词条（覆盖四六级、考研、托福、雅思词表），查词、音标、释义即时返回，无需联网
- **四六级词书**：四级 4544 词、六级 3991 词，支持自定义词书与生词管理
- **造句批改**：「自己造句」与「给我句子」两种模式，AI 按句给出错误原文、原因与修改建议
- **长难句练习**：英译中训练，支持意译判分，附参考表达与句子结构解析
- **收藏与批注**：句子收藏、我的批注、高光标记、文字样式编辑、撤销/重做
- **App 感界面**：启动页过渡、手机端底部导航与抽屉、沉浸模式（隐藏全部 Obsidian 界面元素）
- **多设备互通**：分片存储 + 冲突并集合并，配合文件同步使用，或用内置的自建同步后端

## 安装

- **社区插件市场**：设置 → 第三方插件 → 浏览 → 搜索「英语单词书」
- **手动安装**：从 [Releases](../../releases) 下载 main.js、manifest.json、styles.css，放入 `<仓库>/.obsidian/plugins/english-wordbook/` 后启用
- **BRAT**：将本仓库加入 BRAT 即可安装与更新

## 配置 AI（自带 Key 直连）

设置 → 英语单词书 → AI 接口：选择服务商预设（智谱 GLM、DeepSeek、通义千问、Kimi、硅基流动或自定义 OpenAI 兼容接口），填写 API Key 与模型名，点「发送测试」验证连接。未配置 AI 时，词典查词与内置造句提示可完全离线使用，批改类功能会提示先完成配置。每台设备需分别配置。

## 隐私

本插件不含遥测、广告或追踪代码，作者不运营任何收集用户数据的服务器；详见下方「隐私与数据」一节。

## 版本记录

本版新增可选的自建后端实体级同步（与文件同步互相独立，可只用其一）：

- 服务端为零依赖单文件 `sync/server.js`（Node 18+）：`node server.js` 即可运行，首次启动生成 `config.json`（含端口、数据目录、访问令牌）。建议部署在反向代理（nginx/caddy）后启用 HTTPS；局域网内可直接 http。
- 插件设置页新增「多设备同步」：填服务器地址与访问令牌，点「立即同步」。启动时自动同步一次，改动后约 15 秒自动增量同步。
- 协议为实体级 push/pull：单词、释义、练习记录、词书索引各自独立同步，配合字段级并集合并与 409 版本冲突重试，两台设备并发修改同一单词时双方内容都保留，最终收敛一致。
- 同步内容仅为学习数据；AI Key、界面偏好不上传。同步游标与快照保存在插件目录 `data/sync-state.json`。

此前版本新增 App 感界面：

- 启动页过渡：打开「我的单词书」先显示品牌启动页，内容就绪后淡出（尊重系统「减弱动态效果」设置）。
- 底部导航（手机端）：单词书页面底部新增「词书 / 目录 / 沉浸 / 设置」四键导航。词书打开底部抽屉切换或新建词书；目录打开可搜索的底部抽屉，点单词跳到对应词条；设置直达本插件设置页。桌面端保持原有左侧目录与顶部控件，另在视图右上角新增「沉浸模式」按钮。
- 沉浸模式：隐藏标题栏、标签栏、侧边栏、视图头与状态栏，全屏专注背单词；按 Esc 或底部「退出」返回。关闭页面自动退出。

此前版本新增分片存储，配合文件同步（坚果云等）实现多设备数据互通：

- 学习数据不再集中存放在单个 data.json：每个单词一个词条文件（data/words/），词典条目、批改记录索引、长难句练习、词书列表各自独立成文件（data/ 目录）。两台设备同时学习不同单词时互不覆盖，文件同步的冲突影响范围从「整本书」缩小到「单个词条」。
- 写入保护：保存前若发现某文件在磁盘上已被其他设备更新（版本号更高），先把磁盘旧版另存为 *.conflict-时间戳.json 副本，再与本地改动做并集合并——同一单词在两台设备各自新增的收藏、批注会同时保留，不丢数据。
- 首次启动自动迁移：原 data.json 全量备份为 data.pre-shard.json（该文件此后不再改动），学习数据迁入 data/ 目录，data.json 只保留 AI 设置与界面偏好；迁移中断会在下次启动自动补齐。
- 重新加载插件即可看到其他设备同步来的新增单词；同步方案需覆盖插件目录下新增的 data/ 子文件夹（坚果云全库同步默认包含）。data/ 里的 *.conflict-*.json 是冲突快照，确认无误后可手动删除。
- 回滚到 0.18.x：把 data.pre-shard.json 改名覆盖 data.json，再恢复旧版 main.js/manifest.json 即可。

此前版本新增自带 Key 直连 AI（BYOK），不再强制依赖 Copilot 插件：

- 设置 → 英语单词书新增「AI 接口」配置页：选择服务商预设（智谱 GLM、DeepSeek、通义千问、Kimi、OpenAI 兼容自定义），填写接口地址、API Key 和模型名，点「发送测试」验证连接。配置后批改、查词、问 AI、长难句出题全部直连所选服务商，请求不经过任何中转。
- 未配置或配置不完整时直接给出设置引导，不再回退 Copilot 插件；Copilot 桥接代码已移除，插件只依赖 Obsidian 官方 API。词条头部的「打开 Copilot」按钮变为「AI 设置」，命令面板中的连接检查命令更名为「检查 AI 连接」。
- 直连使用 OpenAI 兼容的 /chat/completions 接口，非流式一次性返回；并发与任务锁语义与旧版一致（同一时间只处理一项 AI 任务）。API Key 明文保存在本插件 data.json 中，请注意仓库同步范围；在设置页更换 Key 会立即生效，无需重载插件。
- 新增「硅基流动」预设（接口地址 https://api.siliconflow.cn/v1，默认模型 Qwen/Qwen3-8B）；选择 Qwen3 系列模型时自动携带 enable_thinking=false 关闭混合推理以缩短批改延迟，并兼容剥离返回正文中的 &lt;think&gt; 块。

此前版本新增内置离线词典、完整四六级词书与自定义词书：

- 内置离线词典：插件目录新增 dictionary.json（约 2 万词条，覆盖四级、六级、考研、托福、雅思词表），添加单词、打开缺失词条和「＋ 从当前词书添加下一个单词」优先查询本地词典，音标与释义即时返回，无需等待 AI，也不消耗 Copilot 额度；词典未收录的词仍按旧流程通过 Copilot 查询。删除 dictionary.json 不会影响已有学习数据，只会退回 AI 查词。
- 完整四六级词书：「大学英语四级词书」约 4500 词、「大学英语六级词书」约 4000 词，词表与词典同源，四六级大部分词条自带中文造句提示，「给我句子」模式可离线使用；个别词暂无内置提示时会显示说明，可切换到「自己造句」。若词典文件缺失，两本书回退为旧的 8 词精选。
- 自定义词书：词书栏新增「新建词书」，输入名称即可创建自己的词书并自动切换过去；选中自定义词书后可「重命名」或「删除词书」（删除有确认弹窗）。自定义词书用原有的「＋ 添加单词」手动录入，同一单词在不同词书间复用学习记录；删除词书只把单词移出本页，收藏、批注和批改记录仍保留。

点击造句栏的收藏按钮后，保存句子和解释，并清空当前模式的造句及批改解释；另一模式的内容不变，收藏中仍可查看完整反馈。

独立页面的单词目录移到页内左侧，保留折叠和中英文搜索。右上角可切换「我的收藏词书」「四级基础精选」「六级进阶精选」，每本保留自己的已添加列表；同一个词在不同书中复用学习记录。精选书各含 8 个本地词条及中文造句提示，是起步内容，不是完整考试词库，也不代表官方词汇分级。

仅在最后一张卡下方保留与卡片同宽的透明边框添加按钮，点击会从当前词书取下一个未添加词，添加后按钮移到新卡下方，卡片之间不保留按钮。全部添加后显示提示；个人词书的按钮打开手动添加。切换词书不会自动请求 AI，精选词的音标、释义和中文提示可离线添加。批改和生成后续练习仍使用 Copilot。

新增独立插件页面：点击 Obsidian 工具栏的书本图标「打开我的单词书」，或在命令面板运行同名命令。安卓和 iOS 也可通过命令面板打开。页面不依赖 Markdown 笔记，词条列表保存在插件 data.json 中。

新版加载时会复制仓库内现有 wordbook 词条及对应学习状态到独立书库；原笔记保留，不自动删除。相同单词只导入一次，已有独立词条不被覆盖；同名词在其他笔记的独立记录仍留在原处。收藏、批注、草稿和翻译练习复制到独立书库，批改记录继续引用「英语练习卡/学习记录」里的原 JSON。迁移完成后，单独删除来源 Markdown 笔记不影响独立书库。插件数据及学习记录仍然是本地文件，请随仓库备份；删除整个仓库或插件数据不在此保护范围内。

安卓与 iOS 适配：恢复手机端缺失词条的自动查词；窄屏单词标题不再为按钮预留大块空白，避免单词被挤成竖排；按钮增加触摸面积，输入框使用 16px 字号；学习文字与批注支持触屏选区。移动端点击添加单词旁的「单词目录」打开左侧栏，选词后自动收起，打开笔记不再自动弹出侧栏。兼容没有 crypto.randomUUID 的 WebView。

本版把内置 AI 从 Claudian 迁移到 Copilot 4。批改、问 AI、查词、生成长难句和翻译检查直接调用 Copilot 的 Quick Chat 当前模型，不再要求打开 Claudian，也不会把整篇当前笔记或 Copilot 对话历史附带给模型。沿用 Copilot 中已经保存的服务商、API Key 和模型选择；不在英语单词书中重复保存密钥。

添加单词旁新增「批量删除」，勾选或全选本页词条后删除；词条标题区新增单独「删除」，确认后从当前笔记移除。删除只移除词条代码块，保留笔记正文、收藏、批注和学习记录，重新添加同一词可恢复学习数据。左侧目录新增搜索框和搜索按钮，支持英文单词（忽略大小写）、中文释义和部分匹配，清空搜索恢复完整目录。

「给我句子」点击「换一句」时清空该模式的造句草稿、当前批改和解释，收起该句提问面板，恢复空白待填写状态。收藏、自己造句模式和旧记录文件保留。上一句延迟返回的批改不会回填到新题；重新打开笔记后也保持已清空状态。

整条文字与批注工具栏随选区显示，取消选择或点空白处整条收起。工具栏新增弯箭头图标「撤销／重做」，支持高光、清除高光、文字编辑、字体样式和恢复原样。原句与个人批注的记录独立，同一段在收藏和批改中的显示同步。每段在当前插件运行期间保留最近 50 步，重启插件清空撤销记录，已保存的文字和标记保留。撤销后进行新修改会清空重做分支；没有可操作记录时箭头变灰。

字体设置工具条只在选中学习文字时出现。取消选区、点击空白处、移到其他输入框或按 Esc 即收起；点击工具条内的字体、字号、颜色等控件不会误收起。批注采用相同操作。

选中文字后，字体、字号和颜色改动即时应用。选择「默认字体／默认字号」或点击「默认颜色」恢复对应的默认样式，不需要「恢复原样」，也不清除高光和文字编辑。「我的批注」写完移开焦点后可直接选中文字高光、设置样式或编辑；批注标记独立于原句，按模式和收藏句子保存。编辑批注内容会清除旧文字位置的标记，避免错位。

「问 AI」固定放在「批改／收藏」旁。选中文字时引用选区，没有选区时引用当前造句。自动初始化 Copilot 的 Quick Chat 模型，不必先打开聊天面板；收到完整回答即回填问题下方，也兼容普通文本回答。单词书请求不写入 Copilot 聊天记录，忙碌时等待上一项任务结束。

批改解释使用“中文提示”等学习用语，不展示内部字段名；区分语法错误、偏离题意和可选润色。比较级可以依靠上下文，不要求显式比较对象。已兼容修正旧记录中已确认的 more time 错误解释。

小标题统一使用 16px 半粗体，正文统一为 15px，以字重和紧凑间距区分层次。单词大标题缩小为 30px（窄屏 28px）。「你的翻译」「参考表达」「句子结构」各占一行，与下面的正文分开。手动设置的正文样式仍然保留。

在 Obsidian 阅读视图中打开「英语练习卡/我的单词书」。

## 使用

- 选中单词书中的学习文字或造句框中的文字，点击「问 AI」，自动引用选中文字及所在段落。直接输入问题，点击「发送问题」或按 Ctrl/Cmd+Enter；回答显示在下面，可继续追问，不用拖到聊天框。使用 Copilot 当前 Quick Chat 模型，不会改动 Copilot 聊天框的草稿和历史。AI 忙时会提示稍后重试，不重复提交。

- 「单词目录」位于 Obsidian 左侧栏，单词从上到下逐行排列，按笔记中的顺序显示；点击标题三角可折叠，点击单词跳到对应词条。切换笔记时目录跟随切换，新增单词自动刷新。页面内不再放置目录。
- 重启插件后左侧目录会自动打开，旧右侧目录会关闭；手动关闭后，可通过命令面板执行「英语单词书：打开左侧单词目录」再次打开。
- 词条默认收起，只保留单词、音标和释义胶带；点击「展开练习」显示造句、收藏、长难句，点击「收起练习」隐藏。展开状态按词条保存。
- 释义默认用胶带遮住；点击「点击查看释义」揭开，点击释义文字或「隐藏释义」重新遮住。不影响练习折叠状态。选中文字编辑时不会误触遮盖，重新打开页面时胶带重新盖住。

- 点「＋ 添加单词」，音标和释义补齐后，新词出现在练习区之前。已有小词库直接显示；其他单词通过 Copilot 当前 Quick Chat 模型查询，通常需要等待其响应，不承诺瞬时完成。结果在本地缓存，不依赖第一次造句。
- 「自己造句」支持多句或短段落；「给我句子」提供中文表达意图，点击「换一句」可轮换。两种模式独立保存草稿，不提供额外英文例句或固定搭配。
- 写完点「批改」。一次支持 6000 字符以内的文本，模型按句给出修改和中文解释，插件直接保存结果。本版已取消图片生成，不创建图片任务，也不等待图片完成。旧图片文件仍保留在原文件夹，词条不再展示图片。
- 每个词条只保留一个造句框，在同一框中继续写下一句、批改。想保留的结果点击「收藏」。不显示新增句子按钮和历史批改列表；旧文件和旧额外输入框的数据仍保留，不删除。
- 「批改」旁点击文字按钮「收藏」，保存当前批改的句子及全部逐点解释。「句子收藏」默认折叠，点击展开；支持取消收藏。收藏是独立保存的内容，重新批改不会改动已收藏的句子。输入已修改但尚未批改时，收藏按钮暂停使用，避免收藏错内容。
- 「自己造句」与「给我句子」分别保存草稿、批改结果、处理状态和收藏；切换模式只显示当前模式的内容。AI 连接一次处理一项任务，另一模式提交时会提示等待，不会冒充正在批改。
- 「我的批注」只放在收藏里，展开输入即可自动保存；按单词、模式和句子分别保存。旧批注保留。
- 造句框内部的小框展示批改。新批改按 1、2、3 列出错误原文（18px 红色）、为什么错、建议怎么改，并给出修改后的表达。旧结果保留原解释及修改建议；旧记录未包含具体错误片段时显示待改原句。不显示「本次原文」、批改完成后的「已保存」或重复批注入口。
- 小框最前面先显示「修改前／修改后」，两边发生变化的文字标红，接着显示编号解释。收藏里采用相同顺序；原有高亮仍可使用。
- 修改前后使用同一字号、字体和行距；解释单独默认折叠，展开后以「错误／改正」分点显示。折叠解释不会隐藏前后对比。
- 选中页面学习文字后显示编辑工具条：可编辑整段文字，也可给所选部分设置字体、字号和颜色，点击「应用样式」生效；「恢复原样」恢复这一段的原始显示。支持单词标题、音标释义、中文造句提示、前后对比、错误解释、收藏内容、长难句及翻译解析。原始 AI 记录不会被修改，页面编辑独立保存；同一内容在批改和收藏中同步显示，模式之间独立。按钮名称等操作控件不属于学习正文。
- 修改段落文字后会清除该段依赖原位置的高亮和手动格式，以免标错位置；前后对比的红色差异会重新计算。编辑不会重新请求 AI 或自动重写原解释。手动样式可以覆盖默认红色。普通笔记正文仍在 Obsidian 编辑视图修改。
- 在批改结果或收藏中，用鼠标选中句子或解释里的一段文字，点击出现的「高亮」即可保存黄色标记。选中标记后点击「清除高亮」可移除所选部分。一次选中同一段文字即可，不跨句子或解释段落。标记按单词、模式、句子和文字内容分别保存；相同内容在批改区与收藏区同步，重开笔记仍保留。
- 升级时从本地记录恢复两种模式的结果，旧收藏能确定来源的归入对应模式，无法确定的保留在「此前收藏（未分类）」中，可点击「移入当前模式」。不删除旧数据。
- 每个词条下面的「长难句练习 · 英译中」提供包含目标词的英文长句，目标词自动标色。先写中文，再点「检查翻译」；系统判断意思是否准确、是否漏译或误解，并展示中文参考表达和句子结构解析。支持意译，不以逐字匹配判断对错。
- 「下一句」保留上一句及其全部作答；「上一句」可回看。同一句反复提交也会保留每次翻译与批改，不覆盖。参考译文在第一次提交之前不显示。
- 当前 adorable / blow up 各有两句内置原创长难句；其他词与后续句子通过现有 AI 准备。以四六级阅读为难度参考，不是真题，也未经难度标定。原阅读选择题入口已隐藏，旧题与答题记录仍保留在插件数据中。

## 更新与启用

社区插件市场安装的版本在 Obsidian 设置 → 第三方插件中点击「检查更新」即可更新。也可以在「设置 → 英语单词书 → 插件更新」中点「检查更新」：插件会从 GitHub 下载新版本并自动重载，无需重启 Obsidian（需要能访问 GitHub；网络受限时请用商店更新）。手动安装的用户把 Releases 中的 main.js、manifest.json、styles.css 覆盖到插件目录后重新启用插件。不要在正在批改时重载插件。
AI 功能需先在「设置 → 英语单词书」中配置接口，可通过命令面板运行「英语单词书：检查 AI 连接」验证。

## 兼容与保存

AI 直连使用 OpenAI 兼容的 /chat/completions 接口（非流式）。请求仅包含本次学习任务（单词、造句或译文与对应提示词），不附带活动笔记、聊天历史或仓库其他内容；同一模式、同一提示、同一句子已有批改时直接复用缓存。
添加单词触发查词：内置词典（dictionary.json，随插件构建内嵌）优先，词典未收录的词通过 AI 查询并缓存。正文内容由 AI 生成可能有误，疑难用法应核对词典。
用户文字仅作为学习数据保存：词条与练习状态存放在插件目录的 data/ 分片文件中，AI 接口与界面设置存放在 data.json；更新插件不覆盖这些文件。生成题目会检查句长、目标词存在和必要答案字段，但语义难度仍由模型决定。

## 隐私与数据

本插件不含任何遥测、统计、广告或追踪代码；插件作者不运营任何收集用户数据的服务器。网络请求只有以下三类，均需你主动操作才会发生：

1. **AI 接口（自带 Key 直连）**：使用批改、AI 查词、问 AI、长难句练习时，插件把当前学习内容（单词、你写的句子或译文、对应提示词）通过 HTTPS 直接发送到你配置的服务商（智谱 GLM、DeepSeek、通义千问、Kimi、硅基流动或自定义 OpenAI 兼容接口）。请求不经过任何中间服务器，插件作者看不到这些内容；服务商按其自身隐私政策处理数据。
2. **自建同步后端（可选，默认关闭）**：你在设置中填入自己的服务器地址与访问令牌后，插件与该服务器同步学习数据（词条、释义、练习记录、词书索引），并发修改按字段级并集合并。AI Key 与界面偏好永不上传；不配置则完全没有此流量。
3. **插件更新检查（仅当你点击设置中的「检查更新」按钮时）**：从 GitHub 查询最新版本并下载新版本文件；不点击则没有任何请求。

**API Key 的存储位置**：Key 保存在插件目录的 data.json 中（Obsidian 插件保存配置的常规位置，明文）。如果你用坚果云、Obsidian Sync 等方式同步整个仓库，data.json 会随之同步到对应云端——请确认你信任这些同步服务，必要时为同步服务使用独立密码或令牌。
**学习数据**：全部保存在你的仓库本地，作者侧没有任何备份；删除仓库即彻底删除数据。

> Privacy (EN): This plugin contains no telemetry, ads, or tracking, and the author operates no servers that collect user data. The only network traffic is (1) direct HTTPS calls to the AI provider you configure with your own API key — only the current word/sentence being practiced is sent, never your notes or other vault contents — and (2) optional sync with a self-hosted server you configure (learning data only; API keys and settings are never uploaded). Your API key is stored in the plugin's data.json inside your vault. The plugin author receives nothing.

## 移动端

安卓与 iOS 的 Obsidian 均可使用。AI 通过自带 Key 直连，不需要 Copilot 插件，也不需要桌面 Agent；仓库同步会把 data.json（含 Key）带到其他设备，也可以在每台设备上单独配置。
更新插件：社区市场安装后一键更新；手动安装则把 Releases 的三个文件复制到手机仓库的 .obsidian/plugins/english-wordbook 目录，重新启用插件。不要用空白 data.json 覆盖已有学习数据。
跨设备同步学习数据：同步方案需覆盖插件目录下的 data/ 子文件夹（坚果云全库同步默认包含），或在设置中配置自建同步后端；两台设备并发修改同一单词时按并集合并，data/ 里的 *.conflict-*.json 是冲突快照，确认无误后可手动删除。
手机切到后台可能被系统暂停，使用 AI 时请保持 Obsidian 在前台。
